Install

  1. Tap the button above and keep the file if Chrome warns you.
  2. Open the finished download, or find WorkLog.apk in your Files app, and tap it.
  3. If Android blocks it, tap Settings, allow installs from this source, go back and tap Install.
  4. If Play Protect warns, tap More details, then Install anyway.

Already have an older Work Log app? Export a backup in Settings, uninstall the old app, then install this one and import the backup.

iPhone: use the web version and Add to Home Screen.
