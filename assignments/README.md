# Assignments

Drop files here and run `/assignment <name>` in Claude Code.

- `inbox/` — the assignment (.pdf/.docx) and, if you have one, the Word template (.docx).
- `my-style/` — 2-3 samples of your own writing (.txt/.docx/.md, a few hundred words each). Used by the voice editor so the text sounds like you. Add these once.
- `work/<name>/` — intermediate files: `brief.md`, `answers.md`, `humanized.md`, `proofread-report.md`.
- `output/` — the finished `<name>.docx`.

Pipeline: brief-analyst → answer-writer → voice-editor → doc-builder → proofreader.

Before submitting, read the result yourself, check the facts and references, and fill any `[STUDENT INPUT NEEDED]` highlights with your own details. No tool can guarantee an AI-detector score.
